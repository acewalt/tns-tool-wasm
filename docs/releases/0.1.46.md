# TNS Tool Portable 0.1.46

Grouped document pages now save divider positions as native integer ratios. An arbitrary mouse drag no longer sends fractional `h1`/`w1` values to the XML bridge. The native validator remains strict. Page selection buttons include their padding in their width and do not move on hover, preventing horizontal scrollbar flicker in Page layout.

Image ScriptApps created by Add image now use their original Lua source and staged image resources inside grouped pages. Independent Lua realms, lifecycle callbacks and resource loading remain active for each application.

Lua Guide now has ten categories and 79 entries, retaining the previous references. New entries cover strings/patterns, tables, protected calls, mathematics and CAS. Insert uses the editor cursor without replacing the document; Try opens a separate preview with no document symbols. Explain describes arguments and common errors; Compare links matching recorded checks from the offline 0.1.45 diagnostic. Functions used in my code ignores comments and string literals. The existing CAS reference, status and examples are reachable within the same navigation. Spanish, English and French are included.

Calculator now preserves `math.eval(...)` and `math.evalStr(...)` entered as symbolic names, evaluating their arguments rather than treating them as Lua VM calls. Quoted strings remain strings. Lua's actual `math.eval` / `math.evalStr` APIs continue to use the CAS bridge normally. Their official Lua input must be a string: [TI API reference](https://education.ti.com/html/eguides/nspire/EG_Nspire/EN/content/eg_lua/m_libraries/mathlibexten/evalstr.HTML).

Validation includes the real Add image flow, two independent Lua panes, a fractional pointer drag through Save/reopen, stable page-button dimensions under real mouse movement, guide insertion/isolation/translations, and the six Calculator expressions from the supplied recording. Also checked 35 non-CAS guide examples through the terminal Lua preview and the existing automated suite. Browser and packaged Windows checks run with external network requests blocked.

Compatibility evidence describes Preview tests, not physical calculator certification. LuaJS bytecode dumping, coroutine suspension and Lua heap controls remain explicitly unsupported. Reference-only entries without an isolated example keep their Try/Insert actions disabled. CAS output can differ algebraically from TI; the app is not a complete TI-Nspire emulator.
