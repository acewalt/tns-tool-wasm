# TNS Tool Portable 0.1.34

- Calculator history now places short expressions and results on the same line, aligned left and right, with alternating white and gray bands. Powers, roots, fractions and matrices use mathematical notation on both sides. Longer cells wrap without changing the existing Prgm text and Request layout.
- The editable calculation and its mathematical preview no longer appear twice: focus edits the original text; leaving the field displays its formatted expression.
- The output filename has a fixed `.tns` suffix outside the editable field. Rename only the basename; pasting a full filename does not duplicate the extension. Enter commits and Escape restores the previous name.
- Moved Math view to the end of Edit. Templates and Catalog use the same green as Edit and Prgm Preview, with slightly thicker icons.
- Corrected light-theme Catalog tabs, lists, selections, controls and icon contrast. Quoted TI-BASIC strings use dark green in the light editor.

Verified Calculator arithmetic and MathML, alternating bands and alignment, entry focus, filename rename/delete/paste/cancel, shared Calculator variables and program calls, editor shortcuts and the existing physics Request layout. The Windows package is built locally from these sources and includes the Ndless SDK.

Extract the complete ZIP into a new folder and open **TNS Tool Portable.exe**. Its title should show **0.1.34**. Preview remains a simulation; the Giac runtime and licenses are unchanged, with its corresponding source bundle in the [0.1.30 release](https://github.com/acewalt/tns-tool-wasm/releases/tag/tns-tool-portable-v0.1.30).
