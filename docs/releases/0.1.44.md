# TNS Tool Portable 0.1.44

Saved application data now reopens from the current staged XML, including when Document Inspector was already open before the save. Genuine stale-save conflicts still fail explicitly.

- Sheets keeps saved values and formulas when reopened from the same Inspector or a grouped page.
- Notes is editable inside layouts, with formatting, direct mathematical templates and native TNS saving. Edits made during a save are flushed before it finishes.
- Page layout has one visual page list, optional multiple selection, valid designs only and a colored arrangement diagram. Drag applications to swap positions; Save layout closes after a successful save.
- Lua ScriptApps can run inside grouped pages with isolated preview runtimes.
- Calculator retains each application's history while navigating the document. Save and layout changes preserve it in TI.Scratchpad; Clear history remains explicit.
- New Graphs pages start empty with their function entry line visible. Enter plots the chosen function.
- Drag a sine/cosine slope to translate the curve, or near a crest/trough to change amplitude and period. Formula labels use mathematical notation and concise coefficients instead of repeatedly nesting expressions.

Preview support remains partial. The Windows portable includes offline runtime assets and the Ndless SDK. Extract the entire ZIP and open **TNS Tool Portable.exe**.
