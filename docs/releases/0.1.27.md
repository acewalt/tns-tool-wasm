# TNS Tool Portable 0.1.27

- Document Inspector hides empty counts and opens the matching app preview from each available app count. Basic counts actual TI.ProgramEditor widgets.
- Grouped Lua, Python, image, spreadsheet, notes, graph, calculator and Program Editor previews show at most three page tabs, with arrows for additional pages. Lua and Prgm retain expanded mode across page changes; notes, sheets, graph and calculator drafts survive navigation within the preview session.
- Prgm Preview matches the Edit button and sits immediately beside it. Translated menus have more room. XML Log keeps a fixed height and scrolls internally.
- Syntax Doctor accepts bare single-expression Func definitions without requiring Prgm/EndPrgm or adding those wrappers in Auto Fix. Program and block-function checks remain active.
- Native Ndless builds respect explicit project build settings and supported declarative Makefile source/object lists. Fallback discovery excludes conventional test directories, preventing multiple main definitions when tests are included in a source ZIP.
- Windows includes the current website changes, native Ndless integration, SDK bundle and local BAT build workflow. Automatic Windows packaging in Actions is disabled; lightweight checks remain automatic.
- Windows download links point to this portable Release, avoiding unrelated compiler-only releases.

Validation: grouped previews with four pages per app, draft retention, rapid tab changes, Lua/Prgm expanded views, 500-line XML Log, CLI end-to-end checks, native startup and C/C++ project creation. The supplied LaplaceLab application compiled to ARM TNS and responded in ARM preview. USB checks use a simulated calculator; no physical calculator verification is claimed.

Extract the complete ZIP into a new folder and open **TNS Tool Portable.exe**. The title must show **0.1.27**. The SDK is included. Native/API and game previews remain partial; they do not emulate the entire TI-Nspire OS.
