# TNS Tool Portable 0.1.32

- Imported TI-BASIC programs stored as document symbols now expose Prgm Preview and Program Editor actions even when the calculator document has no Program Editor page. Graph formulas keep their own tools.
- Prgm Preview executes internal `Define …=Prgm` and multiline `Func` routines with private parameters/Local variables, shared problem variables, returns and bounded call frames.
- The Sonar example now renders its animated radar, reads `T`, accepts a firing angle and Enter, moves the torpedo, and exits with Esc. The preview includes a program keyboard and handles blocking/nonblocking `getKey` calls.
- Added the serialized transpose/inverse-trigonometric glyphs, vector products, normalized vectors, polar coordinates, matrix row/cell assignments, `mat▶list` and `expr` needed by this program.
- Long drawing sessions preserve their pixels using bounded raster checkpoints instead of accumulating an unlimited list of drawing objects.
- Document Inspector has an eye action to show or hide a program's editor page. Hiding preserves the executable symbol, so the program remains callable from Calculator. Showing restores an editor page. This controls page visibility and does not encrypt or protect the source.
- Editing a program is scoped to its selected Problem XML file, including when independent problems use the same program name. Opening the inspector without changing code preserves the stored source representation.

Tested with the supplied Sonar TNS: real import, all nine Program Editor menu categories, preview keyboard/fire/exit, editor show/hide and a save/decode roundtrip with the original executable symbol unchanged. Twelve deterministic stress runs each exercised more than 67,000 instructions and 17,000 drawing operations.

Extract the complete ZIP into a new folder and open **TNS Tool Portable.exe**. The title should show **0.1.32**. The bundled Windows Ndless SDK is retained.

Internal routine behavior follows [TI's subroutine guide](https://education.ti.com/html/webhelp/nspire/4.2/NAVHH/TI-NspireNavigatorHelp_EN/Content/M_Programming/PR_Calling_Another_Program.htm); keyboard values follow the [TI-Nspire reference guide](https://education.ti.com/-/media/1BC0B2849BB04CB18688FA2A8BD3ADC7). Preview remains a simulation rather than a full TI-Nspire emulator. The Giac runtime/licenses are unchanged; its corresponding source bundle remains available in the [0.1.30 release](https://github.com/acewalt/tns-tool-wasm/releases/tag/tns-tool-portable-v0.1.30).
