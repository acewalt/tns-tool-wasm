# TNS Tool Portable 0.1.33

- Prgm Preview opens in Calculator with an editable, prefilled `name()` call. It does not execute until Enter or Run is pressed. You can erase that call, calculate, or call another program in the same problem.
- “+ Page → Calculator” now uses the same screen, controls, history, mathematical formatting and graphics overlay as Prgm Preview. Document programs, including hidden Sonar, are callable from this Calculator. Global values are shared within a problem; `Local` values and arguments stay private.
- Added Var beside Catalog in the Program Editor and Calculator. It lists stored programs, functions and values, including functions defined in Calculator, and inserts at the current cursor.
- Ctrl+B checks syntax in Syntax Doctor and the Lua ScriptApp editor. Ctrl+R opens the corresponding Prgm or LÖVE preview. Windows lets these editor chords bypass its native Reload menu accelerator.
- The Program Editor displays a protected `Define [LibPub/LibPriv] name(parameters)=` header outside the editable source. Document Settings updates it; editing, selecting all or pasting cannot remove it.
- Edit starts with Document Inspector, Document Settings and Program Editor, in that order.
- Fixed the Catalog scrolling area so its last entry remains reachable. Document Libraries can list and open TNS files from a folder the user explicitly selects, such as Downloads. The browser does not silently read Downloads or upload these files.

Verified arithmetic, parameterized Func calls, cross-program calls, shared problem values, private Local values, template/Var insertion, syntax/preview shortcuts, declaration renaming, library filtering, Calculator history save and the original Sonar TNS. The hidden-editor save/decode roundtrip preserves Sonar's stored executable symbol. Sonar's radar, keyboard input, torpedo and graphics checkpoints continue to work after explicit execution.

Extract the complete ZIP into a new folder and open **TNS Tool Portable.exe**. Its title should show **0.1.33**. The Windows Ndless SDK is retained. Preview remains a simulation with unsupported operations reported explicitly. The Giac runtime/licenses are unchanged; its corresponding source bundle remains available in the [0.1.30 release](https://github.com/acewalt/tns-tool-wasm/releases/tag/tns-tool-portable-v0.1.30).
