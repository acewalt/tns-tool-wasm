# TNS Tool Portable 0.1.43

Page layout now opens above the current preview, restores focus on close and identifies each page by its native application types.

- Edit Sheets inside grouped pages, enter formulas with cell/range picking and keep dependent values up to date. Valid outer parentheses are simplified; necessary grouping is preserved.
- Use Program Editor, Calculator, Python Editor and Python Shell in layouts. BASIC Run prepares a Calculator call; Enter executes it. Python editor/shell transitions preserve source and avoid duplicate buffers.
- Insert Notes templates directly at the caret. Edit expressions in place, retain text styles and save native mathematical XML.
- Preserve other apps and namespace/CR data when saving Sheets. Stale file or widget identities are rejected instead of updating a different sheet.
- Keep zoom and expanded-view controls on the page header when apps are embedded.

The Windows package includes the browser/runtime assets for offline use. Preview support is partial; this is not a full TI-Nspire OS emulator. Ndless C/C++ compilation continues to use the bundled Windows SDK.
