# TNS Tool Portable 0.1.28

- Shared calculator headers: up to three real page tabs, document title centered across the display, RAD/DEG, battery, close control and a thin cyan divider. Single-page previews show their real current tab too.
- Page switches retain the same outer preview window and remove closing/opening animations. Drafts and expanded mode continue to survive navigation.
- Widgets is the first Inspector summary item and becomes an amber (#FBBF24) preview button when there is more than one widget. It browses all widgets in document order, routing to the appropriate existing app preview. Unsupported widget types are identified explicitly.
- Image preview uses one calculator header and a 320x214 image viewport beneath it. Pan the original pixels, fit the complete image or expand the viewport to see more. Navigation no longer sits separately above a canvas with a hardcoded page number.
- Lua ScriptApp Edit actions, clipboard menus, prompts and status messages follow English, Spanish or French, including language changes while the menu is open.
- Includes the current website and native Ndless features from 0.1.27. Windows packaging remains local; the BAT and build helper are included in the source archive.

Extract the entire ZIP into a new folder and open **TNS Tool Portable.exe**. The title should display **0.1.28**. Previews remain partial simulations rather than a complete TI-Nspire OS emulator.

Validation: 30 targeted navigation, widget routing, language and TI-BASIC tests; a real Chromium scenario with 26 document apps across all eight preview families; repeated page changes with the same backdrop and no rendered inspector flash; draft retention; a 1009x310 image tested for native pixels, horizontal/vertical pan, fit and expanded viewport. Native C/C++ startup and existing manager/Prgm checks passed.
