# TNS Tool Portable 0.1.30

- Consistent LÖVE/Lua D-pad controls on the first frame, icon buttons for math templates and catalog, and palettes opening below their controls.
- Program Editor in Edit: nine icon categories and 394 actions/snippets, shown only for actual TI.ProgramEditor widgets. Syntax verification, store and run are grouped there. Editor actions support new/open/import/view/copy/rename/library access, comments, find/replace and line navigation.
- Shared 25-template palette and searchable 754-entry catalog in Syntax Doctor, Calculator and Lua math tools. Matrix, system and piecewise dimensions are selected before insertion.
- Optional editable 2D mathematical view preserves TI source text and renders fractions, roots, matrices, cases, calculus and subscripts with MathML.
- Shared bounded TI-BASIC numeric engine for Program Preview and Calculator: lists/matrices, newMat, randMat, identity, diag, random functions, modes, Loop/Goto and error control.
- Local Giac/Xcas WebAssembly handles symbolic Calculator operations without external runtime requests. Calculator sessions retain their own variables and functions.
- Widgets keeps its amber button with a prominent plus sign.

Extract the entire ZIP into a new folder and open **TNS Tool Portable.exe**; check **0.1.30** in its title. The bundled Ndless SDK and current native features are retained. Preview is a partial simulation. Catalog insertion and code templates include commands that require real TI hardware or a platform-specific API; those are not silently simulated as successful calculations.

Giac/Xcas licenses are included under assets/cas. Corresponding upstream source archives, dependency sources and build instructions are supplied separately as **TNS-Giac-CAS-Source.tar.gz**, with SHA256. See assets/cas/README.md for provenance and source availability.

Validation: 54 shared-preview layout cases, eight end-to-end math/editor cases, four viewport/theme combinations, 12 offline Calculator/CAS isolation cases and 18 offline Giac probes passed. The Calculator UI tests use Enter and copied screen output, including a cold CAS start, matrices, derivatives, factorization and integration. Numeric/template/menu unit tests and the existing desktop regression checks also passed.
