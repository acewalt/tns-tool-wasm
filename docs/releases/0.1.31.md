# TNS Tool Portable 0.1.31

- Math view keeps the actual text cursor and selection while templates or the catalog are open. Enter creates lines, and switching Program Editors preserves the edited source.
- The catalog has a symbols grid, a Conversion tab with units/constants, and the supplied mathematical operator hierarchy with parameter assistants.
- Program Editor is first in Edit and opens beside the menu, aligned with its top edge. Catalog and template palettes fit the available viewport.
- Calculator has one template/catalog pair and no redundant Cancel action. Editable mathematical entries grow to fit matrices and systems; history uses two-dimensional mathematical notation.
- Prgm Preview supports a separate retained graphics surface, RGB shapes/text, coordinate windows, pen styles, buffering and animated frames. The included `examples/cx-ii-drawing-test.tib` reproduces the supplied drawing example.
- Failed USB interface claims show recovery guidance, a retry action and Windows WinUSB/Zadig setup steps for the selected TI-Nspire. The website does not install drivers automatically.
- Syntax Doctor recognizes the supplied catalog's unit and constant tokens while still reporting unknown variable names.
- Syntax Doctor handles nested `Define …=Prgm`/`Func` routines, scoped local variables, Unicode identifiers and indexed `:=` assignments. Auto Fix preserves nested closures and local declarations. The supplied 239-line sonar program analyzes without false errors before and after Auto Fix; this does not certify execution of the full game in preview.

Extract the full ZIP into a new folder and open **TNS Tool Portable.exe**. Check **0.1.31** in the window title. Windows Ndless support and the bundled SDK are retained. Preview remains a simulation; adding a catalog item does not imply that every hardware or OS command can execute in the browser.

Drawing semantics follow the [TI drawing command guide](https://education.ti.com/html/webhelp/EG_TINspireCode/EN/Subsystems/RG_Nspire_EN/Content/M_RefGuide/RG_DrawCommand.htm). USB guidance links to [Zadig's official website](https://zadig.akeo.ie/) and is based on [WebUSB's interface requirements](https://developer.chrome.com/docs/capabilities/build-for-webusb).

The Giac runtime and licenses are unchanged from 0.1.30. Its corresponding source bundle remains available in the [0.1.30 release](https://github.com/acewalt/tns-tool-wasm/releases/tag/tns-tool-portable-v0.1.30).

Validation includes 59 Python syntax regressions (including colon-prefixed TI statements), 54 preview layout cases, real cursor/draft preservation checks, 25 calculator templates, six calculator computations, catalog assistants, mocked USB recovery/retry, and the supplied drawing example with timed/buffered animation.
