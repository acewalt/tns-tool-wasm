# TNS Tool Portable 0.1.29

- All document previews share one window layout and display anchor. Moving between TI-BASIC, Lua/LÖVE, Notes, Sheets, Graphs, Calculator, Images and Python keeps the screen in the same place.
- Shared rounded corners, a thin border, an opaque background and the same spacing as Prgm Preview.
- Normal and expanded views use the same controls area and resize the display without scaling the surrounding interface. Controls wrap on narrow windows.
- Lua math tools reuse the common layout instead of creating a nested workspace after loading.
- Keeps the amber Widgets button, real calculator page tabs, persistent drafts and current native Ndless features.

Extract the entire ZIP into a new folder and open **TNS Tool Portable.exe**. The title should display **0.1.29**. Previews remain partial simulations rather than a complete TI-Nspire OS emulator.

Validation: 30 targeted navigation, widget routing, language and TI-BASIC tests. Real Chromium checks cover 48 widget views (eight app types, three window sizes, normal/expanded), six standalone Lua views, unsupported-widget fallback, input/copy controls, exact matching display positions, borders, draft retention and Calculator canvas repaint after resizing.
