# TNS Tool Portable 0.1.35

- Basic and Widgets in Document Inspector now open a TI.ProgramEditor preview instead of immediately showing Calculator. Its 320×240 display has the red editor header, program name, line counter, TI light source colors and a protected `Define [LibPub/LibPriv] name(parameters)=` declaration outside the editable source.
- Each TI.ProgramEditor row has separate **Open editor** and **Prgm Preview** actions. Editing remains synchronized with Syntax Doctor; checking and saving use its existing validator. Ctrl+B checks syntax. Run and Ctrl+R open Calculator with the program call filled in and wait for Enter before executing.
- Preview navigation retains editor drafts and uses the same display position, tabs and expanded layout as the other document apps.
- Mathematical source view is enabled by default, including notation such as `abs(x)` → `|x|`. Templates, Catalog and Var insert at the active source caret. Switching views or opening a syntax diagnostic does not replace the selected source text.
- Elements show a contextual × action on hover, keyboard focus or touch. Confirmation names the exact target before changing the staged document. Removing an editor page keeps its callable program; removing a stored program also removes its editor pages. Removing a complete card includes its contained apps. A final or split page keeps a valid blank Calculator slot.
- Referenced resources cannot be removed independently while an app still uses them. Stale selections are refused. Unrelated unsaved or invalid source drafts survive deletion, and Inspector remains available while a program is unfinished.

Built locally for Windows with the included Ndless SDK. Extract the complete ZIP into a new folder and open **TNS Tool Portable.exe**; the title should show **0.1.35**. The Giac runtime/licenses are unchanged; its corresponding source bundle remains in the [0.1.30 release](https://github.com/acewalt/tns-tool-wasm/releases/tag/tns-tool-portable-v0.1.30).
