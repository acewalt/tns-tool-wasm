# TNS Tool Portable 0.1.45

Grouped applications keep their own controls and use the full assigned area. Calculator scrolls its transcript without moving the page or zoom frame. Notes formatting appears above the display, with a separate toolbar for the active Notes application. Page layout is available from the top header of every supported application preview.

- Calculator works across horizontal, vertical and resized layouts, including normal, magnified and expanded views.
- Notes preserves bold, italic, size and color in native XML, without applying the active selection to another Notes application.
- Page layout opens above the current preview and retains unsaved editor text and Calculator input.
- Lua compatibility changes and comparative diagnostic results are described in [the Lua validation report](../lua-compatibility-v45.md).

The Windows ZIP includes the local runtime assets and Ndless SDK. Extract the entire archive and open **TNS Tool Portable.exe**. Preview coverage is partial; it is not a complete TI-Nspire emulator.
