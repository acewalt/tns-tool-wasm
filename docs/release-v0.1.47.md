# TNS Tool Portable 0.1.47 — Lua Visual Builder

Lua ScriptApp now includes **Edit → Lua Visual Builder** and a shortcut beside Preview Lua.

- Visual designer: 15 component types, drag/resize, properties, parents, layers, grid, reusable components and themes.
- Multiple screens with navigation, page history, keyboard focus and six starter templates.
- Simple event actions and formula bindings; advanced execution/data nodes with conditions, variables, loops, delays, CAS and custom Lua.
- Isolated execution of generated TI-Nspire Lua in Preview; projects can be reopened from embedded metadata or exported as JSON.
- Apply to the current ScriptApp, download Lua, or build TNS using the existing document export. Local autosave and undo/redo are included.
- Available in Spanish, English and French. Browser and portable share the builder. Portable assets are bundled for offline use.

Validation covers generated Lua execution, navigation and controls, node connections and renaming, local/global variables, bounded queues, real browser integration, metadata restoration, TNS roundtrip and packaged offline execution. Physical calculator compatibility remains to be tested on hardware. Arbitrary handwritten Lua is preserved, but is not automatically reverse-engineered into a visual design.

See [the builder guide](lua-visual-builder.md) for controls, supported APIs and limits.
